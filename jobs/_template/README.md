# Job template

Copy this directory to `jobs/<id>/` and replace every placeholder.

- `strategy` — one of the ids in `docs/strategies.md`
- `media` — any of `video`, `audio`, `still`, `text`
- `rights` — `funded-brief`, `owned`, or `licensed`
- `distribution_identity` — the operator's label for the account. Null only while this file is still the template.

Leave the subject out of the engine docs. Put it in this folder after you copy.
